# نمایش تماس‌های ورودی مرکز تماس نورون

در هر مطب، از «تنظیمات ← ارتباط با VoIP» ابتدا ارتباط اصلی و توکن آن را فعال کنید، سپس «نمایش تماس‌های ورودی» را روشن کنید. آدرس کامل وب‌هوک در همان بخش نمایش داده می‌شود:

```text
https://DOMAIN/external-api/voip/v1/call-events
```

در مرکز تماس، روش `POST`، بدنهٔ `application/json` و هدر `Authorization: Bearer TOKEN` را تنظیم کنید. `TOKEN` همان توکن API مطب است. این توکن هویت مطب را تعیین می‌کند؛ ارسال بدون توکن یا وقتی یکی از دو گزینهٔ VoIP غیرفعال باشد، با `401` رد می‌شود. رمز امضای اختیاری مرکز تماس برای این اتصال تنظیم نشود؛ احراز هویت با Bearer انجام می‌شود.

برای فهرست و وضعیت لحظه‌ای، رویدادهای `call.started` و `call.ended` را حتماً فعال کنید. رویدادهای `call.queued`، `call.ringing` و `call.answered` مراحل میانی را به‌روز می‌کنند. سایر رویدادهای شناخته‌شده نیز ذخیره می‌شوند. رویداد ناشناخته پاسخ `200` می‌گیرد و نادیده گرفته می‌شود. رویداد `test:true` نیز پاسخ `200` می‌گیرد، ولی وارد فهرست تماس‌های واقعی نمی‌شود.

درخواست معتبر ابتدا با `eventId` یکتا در دیتابیس همان مطب ذخیره می‌شود. تماس‌های خروجی در فهرست تماس‌های ورودی نمایش داده نمی‌شوند. ترتیب وضعیت با `seq` حفظ می‌شود و `call.ended` حتی اگر رویداد آغاز تماس نرسیده باشد، تماس ورودی را ثبت می‌کند. فهرست داخل تنظیمات هر پنج ثانیه تازه می‌شود.

پس از انتشار کد روی سرور، migrationهای اجرا‌نشدهٔ tenantها را اجرا کنید:

```sh
cd /www/wwwroot2/dastgheib/backend
php artisan tenants:migrate --force
```

این migration دو جدول جدید `voip_call_events` و `voip_calls` می‌سازد و جدول‌های تماس قبلی را تغییر نمی‌دهد. برای آزمون اتصال، از دکمهٔ «ارسال تست» مرکز تماس استفاده کنید و پاسخ `200` را در گزارش ارسال‌های آن بررسی کنید؛ سپس یک تماس واقعی بگیرید تا در فهرست مطب دیده شود.
